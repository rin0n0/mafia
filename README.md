# Mafia Gemini: AI-Powered Mafia Game

https://mafia.rinnxx.ru

**Mafia Gemini** — это веб-платформа для игры в классическую "Мафию", где роль ведущего выполняет генеративная нейросеть (Gemini). Проект создан для обеспечения глубоко атмосферного и реиграбельного игрового опыта, минимизируя человеческий фактор в роли ведущего и усиливая ролевую составляющую для игроков.

## 🚀 Ключевые особенности

*   **🤖 AI-Ведущий (Gemini):** Весь повествовательный текст, от описания ночных событий до итогов голосований, генерируется нейросетью в реальном времени.
*   **🎨 Атмосферность и реиграбельность:** Игроки сами задают сеттинг для игры (например, "Криминальная Россия", "Киберпанк", "Викторианский Лондон"), и AI-ведущий адаптирует весь нарратив под выбранный стиль. Каждая партия — это уникальная история.
*   **🗣️ Интерактивность:** Игроки свободно обсуждают, голосуют и совершают действия. Платформа обрабатывает их решения, а AI-ведущий красочно описывает последствия.
*   **🤝 Командное взаимодействие:** Роли с общими целями (например, Мафия) действуют как команда. Они видят выбор своих союзников в реальном времени, что позволяет координировать действия без слов.
*   **🎮 Полный игровой цикл:** Реализован весь цикл игры: от создания лобби и настройки ролей до определения победителя, включая фазы знакомства, дня, ночи и голосования.
*   **🔐 Без регистрации:** Быстрый вход в игру без необходимости создавать аккаунт. Идентификация происходит по уникальному ID в `localStorage`.

## 🛠️ Технологический стек

Проект построен на современном и производительном стеке с четким разделением на Frontend и Backend.

### Frontend (Клиент)

*   **Фреймворк:** **Vue.js 3** (Composition API, `<script setup>`)
*   **Язык:** **TypeScript**
*   **Управление состоянием:** **Pinia** (с разделением на `userStore`, `gameStore`, `uiStore`)
*   **Связь с бэкендом:**
    *   **Axios** для HTTP REST API (действия, инициируемые клиентом).
    *   Нативный **WebSocket API** для real-time обновлений состояния от сервера.
*   **Качество кода:** ESLint

### Backend (Сервер)

*   **Фреймворк:** **FastAPI** (асинхронный Python)
*   **Сервер:** **Uvicorn**
*   **Валидация данных:** **Pydantic**
*   **AI-интеграция:** **Google GenAI SDK** (Gemini 2.5 Flash)
*   **Связь с клиентом:**
    *   **HTTP REST API** для разовых действий (создание/вход в комнату, настройки).
    *   **WebSockets** для мгновенной рассылки персональных обновлений состояния (`personal_state_update`).

## 🏛️ Архитектура

Архитектура проекта спроектирована для обеспечения надежности, масштабируемости и чистоты кода.

*   **Единый источник правды:** Бэкенд является единственным источником правды. Вся игровая логика, таймеры и состояния управляются сервером, что гарантирует синхронизацию между всеми игроками.
*   **Конечный автомат:** `GameManager` на бэкенде реализован как явная машина состояний, управляющая игровым циклом и переходами между фазами.
*   **Изоляция зависимостей (Dependency Injection):** Компоненты бэкенда (`GameManager`, `GameNotifier`, `ConnectionManager`) создаются и связываются в одной точке (`main.py`), что делает систему модульной и тестируемой.
*   **Безопасность состояния:** Для предотвращения гонок состояний при одновременных действиях игроков используется `asyncio.Lock` на каждую игровую комнату.
*   **Умная рассылка:** Вместо "глупых" публичных рассылок используется `GameNotifier`, который отправляет каждому игроку его **персональное** представление игрового мира, включая приватную информацию (роль, статус действия).
*   **Упреждающая генерация AI-контента:** Чтобы скрыть задержки API нейросети, система в фоне генерирует текст для следующей фазы, пока идет текущая. Это создает ощущение мгновенного ответа от AI-ведущего.

## ⚙️ Локальный запуск

Для запуска проекта на локальной машине выполните следующие шаги.

### Предварительные требования

*   Python 3.10+
*   Node.js 18+
*   Менеджер пакетов `npm` или `yarn`

### Настройка Backend

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/mafia-gemini.git
    cd mafia-gemini/back-end
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    # Windows
    .\venv\Scripts\activate
    # macOS / Linux
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройте переменные окружения:**
    *   Создайте файл `.env` в корне папки `back-end`.
    *   Добавьте в него ваш API-ключ от Gemini:
        ```env
        GEMINI_API_KEY="your_api_key_here"
        ```

5.  **Запустите сервер:**
    ```bash
    uvicorn main:app --reload
    ```
    Сервер будет доступен по адресу `http://127.0.0.1:8000`.

### Настройка Frontend

1.  **Перейдите в папку фронтенда:**
    ```bash
    cd ../front-end
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки:**
    ```bash
    vue serve
    ```
    Клиентское приложение будет доступно по адресу, указанному в консоли. Откройте эту ссылку в браузере, чтобы начать игру.
